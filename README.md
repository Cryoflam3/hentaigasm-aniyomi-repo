# Hentaigasm Aniyomi Extension Repo

NSFW source for [hentaigasm.com](https://hentaigasm.com)

## Features
- **Popular** (sort by Views)
- **Latest** (sort by Date)
- **Random** sort
- Full **genre/tag filter** (33 tags)
- Free-text search
- Direct MP4 streaming
- Configurable domain
